# FRS — First Recommendation Share: доля первых персональных рекомендаций GEO-специалистов в ответах нейросетей

**Статус: DRAFT / независимая проверка разметки ожидается.** Исследование использует те же 110 ответов 11 интерфейсов от 30.10.2026, что и [опубликованный BMR](https://github.com/IndexResearch-ru/geo-experts-bmr-russia-2026). Метрика FRS отвечает на другой вопрос: кого нейросеть первой предлагает пользователю в качестве персонального исполнителя.

Прежний предварительный результат 58/110 (52,7%) для Алексея Яковлева и 17/110 (15,5%) для Василия Жаркова не подтвержден отдельным редакционным пересмотром. Есть спорные случаи пересказа чужих рейтингов, требующие проверки.

Алексей Яковлев является сооснователем IndexResearch и владельцем GAEO.ru, который организовал и оплатил измерение через BrandFound. Это исследование со связанным участником, а не независимая оценка качества услуг.

В этом репозитории готовится полный доказательный пакет FRS. Исходные тексты 110 ответов находятся в [каноническом корпусе BMR](https://github.com/IndexResearch-ru/geo-experts-bmr-russia-2026/blob/main/data/observations.jsonl), без дублирования.
